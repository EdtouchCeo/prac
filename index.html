학교 민원 개인정보 보호 가이드

로컬 전용 데이터 보존 원칙 모든 데이터는 교사의 PC 브라우저(LocalStorage)에만 보관되며 외부 서버로 저장되지 않습니다.
학생 개인정보 최소화 (실명 사용 금지)

답변 작성 시 학생 실명 대신 'A학생', '해당 학생'과 같이 익명 또는 별명 표기를 사용하십시오.

제3자(타 학생) 개인정보 비공개 원칙

학교폭력 또는 갈등 민원 시 가해/피해 상대 학생의 인적사항이나 가정환경은 절대 유출할 수 없습니다.

사용법 안내

1. 원하는 민원 템플릿을 좌측 목록에서 선택합니다.

2. 필수 가변 정보(학부모 성함, 조치 일자 등)를 입력하면 초안이 실시간으로 완성됩니다.

3. 상단 [AI 키 설정]에서 Gemini API 키를 등록하면 AI 어조 다듬기 기능을 이용할 수 있습니다.

4. [클립보드 복사] 또는 [.txt 파일 저장] 버튼을 눌러 활용하세요.
